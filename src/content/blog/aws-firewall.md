“Stop sending all your traffic through a single firewall.”
 That statement really hit me during the AWS Experience Iberia virtual session last month — and it perfectly sums up how cloud security is evolving.

Security in the cloud is no longer about blocking everything; it’s about building agility and visibility into every layer of your infrastructure.

The session "Firewalls on AWS: When and How to Protect Your Infrastructure" went deep into modern network protection patterns and best practices for scaling securely.
 Some key takeaways that stood out to me:
- ✅ Shared responsibility is key — AWS secures of the cloud, while we secure in the cloud.
- ✅ Layered protection with AWS WAF, Shield, Network Firewall, and Firewall Manager to cover from L3 to L7.
- ✅ Centralized and distributed inspection models to balance cost, performance, and blast radius.
- ✅ Automation and observability through Security Hub, GuardDuty, Inspector, and Systems Manager — making remediation proactive, not reactive.
Security on AWS isn’t about slowing down innovation — it’s about enabling it, safely.
